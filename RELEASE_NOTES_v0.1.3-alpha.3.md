# Megarift Survivors v0.1.3-alpha.3 (test build)

Released 2026-11-02 as a pre-release for testing. Install over 0.1.3-alpha.2 (Android version code 16): your progress is kept.

## Fixes
- **What's new scrolls again:** the release list and the notes each scroll on their own, so long notes can be read to the end on any screen (swipe, mouse wheel or D-pad). The long list of releases used to make the page taller than the screen, so the notes could not scroll. The selected release is always in view when the screen opens.

## Downloads
- Android: `megarift-survivors-0.1.3-alpha.3.apk`
- Windows: `megarift-survivors-0.1.3-alpha.3-windows.zip` (unzip and run Megarift Survivors.exe)
